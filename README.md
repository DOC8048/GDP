
# Мировой ВВП: исторические данные и прогноз (1925–2026)

Веб-приложение на Streamlit, объединяющее исторические данные Maddison Project Database с прогнозами IMF WEO.

## Что на графиках

**Верхний график — мировой ВВП в долларах по годам.** Абсолютные значения: сколько всего произвела мировая экономика. Показаны два набора:
- Фиксированный набор стран (доступны в 1925 году) — сплошная синяя линия
- Все страны — оранжевая линия

**Нижний график — годовой рост ВВП в процентах.** Скорость изменения по сравнению с предыдущим годом. Столбцы вниз — кризисы. Аннотированы ключевые события: Великая депрессия, Вторая мировая,кризис 2009, COVID-19, Банковский кризис 2023.

## Источники данных

- **1925–2022:** Bolt and van Zanden — Maddison Project Database 2023 (Eurostat, OECD, IMF, World Bank)
- **2023–2026:** IMF World Economic Outlook (апрель 2025), показатель NGDP_RPCH (Real GDP growth rate)

## Методология

- ВВП считается как `gdppc × pop × 1000` (ВВП на душу населения × население в тысячах)
- Прогноз 2023–2026 строится постречно: ВВП каждой страны умножается на темп роста из WEO, затем суммируется
- Точка 2022 года входит и в историческую часть, и в прогноз — для бесшовного перехода
